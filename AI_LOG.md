# AI Log — Kvitto Payments API

## Как использовался ИИ

ИИ помогал разбирать требования, планировать реализацию и проверять решения для API платежей на FastAPI, PostgreSQL, Alembic и Docker Compose. В предоставленном описании работы обсуждались денежные расчёты в целых копейках, график рассрочки, идемпотентность запросов и переходы статусов.

Среди важных уточнений: сумма графика должна точно совпадать с итоговой суммой платежа; для `1990000` копеек на 3 месяца ожидается `[663334, 663333, 663333]`. Для `Idempotency-Key` одной проверки перед вставкой недостаточно из-за возможной гонки, поэтому требуется уникальное ограничение в базе и обработка конфликта. Ошибка запрещённого перехода должна возвращаться как `{"error":"invalid_transition"}` на верхнем уровне, а статус после отказа не должен меняться.

Этот журнал кратко передаёт предоставленное описание взаимодействия. Он не является дословной историей разработки и не подтверждает, кто написал каждый файл.
